Inside the product

Explore the workspace

From the first draft to the published site, each part of the workspace serves a different job.

Content and revisions

Edit pages and posts in a block editor. Preview a localized draft, organize content with taxonomies, and revisit revisions when a piece needs to change.

Editorial workflows

Move posts through configured stages on a Kanban board. Simulate a workflow before applying it to see which transitions and checks a draft would encounter.

Shared media library

Browse and select assets while editing. Preview supported images, documents, audio, video, and 3D files in the file manager.

Languages and localization

Manage active languages and edit localized content. The admin supports English and Persian, right-to-left layouts, and language-aware dates.

Role-based access

Use Rolix to grant access to specific admin pages and actions. Editorial workflows can further restrict which stages and transitions a role can use.

Extensions and integration

Extend Jobic through hooks, Laravel service providers, and registered views. Manage compatible extensions through installation, activation, and upgrades.

Architecture

Laravel is the core of Jobic

Your site remains a Laravel application. Use Eloquent for data, Blade for views, policies for authorization, and queues for background work. When the business needs a custom feature, your team can build it with familiar Laravel conventions.

Jobic assembles open-source JobMetric packages for common application needs. Teams can inspect those packages, contribute improvements, and use them independently.

Getting started

From installation to your first site

  1. Prepare your environment

    Set up a Laravel-compatible PHP environment, Redis, and an empty MySQL, MariaDB, or PostgreSQL database. Point the web server at the application's public directory.

  2. Run the setup wizard

    Open the site to configure the database and Redis, choose the initial language, and create the administrator account.

  3. Set up your workspace

    Choose your content structure and roles, add your design, and extend the application as your project needs grow.

Common questions

Can our developers use their existing Laravel skills?

Yes. Jobic uses standard Laravel code for models, policies, views, queues, and integrations. Your team can build project-specific behavior using the same framework.

Can we build a multilingual site?

Jobic supports language-specific content, active language management, and English and Persian admin interfaces. Your theme and custom modules can provide their own translations.

Does Jobic include a ready-to-run store?

Jobic supplies the CMS foundation. Storefront features such as checkout and payments depend on the modules and integrations you build or install.

Can we use JobMetric packages separately?

Yes. The packages have their own documentation and can be adopted independently where they fit your Laravel application.
